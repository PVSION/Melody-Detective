# Melody Detective Version 0.1 Plan

## Goal

Build the smallest playable version of Melody Detective.

The app should play one mystery note and ask the user to find it on a virtual piano.

## User Flow

1. The page loads and chooses a mystery note.
2. The user presses **Play Note**.
3. The browser plays the mystery note.
4. The user clicks a piano key.
5. The app compares the clicked note with the mystery note.
6. The app shows one response:
   - **Correct**
   - **Too High**
   - **Too Low**
7. After a correct answer, the app chooses a new mystery note.

## Version 0.1 Limits

This version intentionally does not include:

- User accounts
- Saved progress
- Scoring
- Levels
- A database
- A backend server
- React or other frameworks
- Build tools

Keeping the first version small makes it easier to understand, test, and improve.
